## ✨ Overview

**AI Codebase Analyzer** clones any public GitHub repository, breaks it into semantically meaningful chunks, embeds them into a vector index, and lets you ask natural-language questions about the codebase — answered with real, retrieved source snippets instead of guesses.

Point it at a repo. Ask "How does routing work?" or "Where is authentication handled?" Get grounded, accurate answers in seconds.

---

## 🚀 Features

- 🔍 **Semantic code search** — FAISS-powered vector similarity over embedded source chunks
- 💬 **Grounded Q&A** — Answers generated by Groq's Llama 3.3 70B, backed by retrieved code
- 📊 **Repository insights** — Instant file counts, chunk counts, and detected languages
- 🕸️ **Python import graph** — Visual dependency mapping across modules
- 🎨 **Modern, animated UI** — Sleek Next.js frontend with glassmorphism and smooth motion
- ⚡ **Fast setup** — One command to run the full stack locally

## 🖥️ Getting Started

### 1. Backend

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env          # add your GROQ_API_KEY
uvicorn app.api:app --reload --port 8000
```

### 2. Frontend

```bash
cd web
cp .env.local.example .env.local
npm install
npm run dev
```

Open **http://localhost:3000** 🎉

### One-command start

```bash
cd web && npm install && cd ..
./run.sh
```

## ☁️ Deployment

### Frontend → Vercel

1. Import this repo at [vercel.com/new](https://vercel.com/new)
2. Set **Root Directory** to `web`
3. Add environment variable `NEXT_PUBLIC_API_URL` → your backend URL
4. Deploy

### Backend → Render

1. Create a new **Blueprint** at [Render](https://render.com/) and point it at this repo
2. Render auto-detects `render.yaml`
3. Add your `GROQ_API_KEY` and `CORS_ORIGINS` (your Vercel URL) as environment variables
4. Deploy
